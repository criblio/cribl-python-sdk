      Scale (provision) a Worker Group#

      Cribl.Cloud example_cloud_scale_worker_group.py

      Update estimated ingest rate.

      This example is for Cribl.Cloud deployments only.

      Prerequisites#

      • pip install cribl-python-sdk
      • CRIBL_CLIENT_ID and CRIBL_CLIENT_SECRET env vars
      • CRIBL_CLOUD_URL env var
      • An existing Worker Group to scale

      Environment variables#

      VariableDefault
      CRIBL_CLIENT_IDyour-client-id
      CRIBL_CLIENT_SECRETyour-client-secret
      CRIBL_CLOUD_URLhttps://main-your-org.cribl.cloud
      CRIBL_WORKER_GROUP_IDmy-worker-group
