      Configure Resources#

      Cribl.Cloud example_cloud_configure_resources.py

      Create source, destination, pipeline, route in a Worker Group.

      This example is for Cribl.Cloud deployments only.

      Prerequisites#

      • pip install cribl-python-sdk
      • CRIBL_CLIENT_ID and CRIBL_CLIENT_SECRET env vars
      • CRIBL_CLOUD_URL env var
      • AWS credentials for the S3 destination

      Environment variables#

      VariableDefault
      CRIBL_CLIENT_IDyour-client-id
      CRIBL_CLIENT_SECRETyour-client-secret
      CRIBL_CLOUD_URLhttps://main-your-org.cribl.cloud
      CRIBL_WORKER_GROUP_IDmy-group
      AWS_ACCESS_KEY_IDyour-aws-key
      AWS_SECRET_ACCESS_KEYyour-aws-secret
      AWS_BUCKET_NAMEyour-bucket
      AWS_REGIONus-east-2
