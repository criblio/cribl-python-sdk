      install#

      client.packs.install(...)
await client.packs.install_async(...)

      Install a Pack.

      Install a Pack. To install an uploaded Pack, provide the source value from the PUT /packs response as the source parameter in the request body. To install a Pack by importing from a URL, provide the direct URL location of the .crbl file for the Pack as the source parameter in the request body. To install a Pack by importing from a Git repository, provide git+<repo-url> as the source parameter in the request body. If you do not include the source parameter in the request body, an empty Pack is created.

      Example Usage#

      # Example request body for installing a Pack directly from the Cribl Pack Dispensary using a download URL.
client.packs.install(
    source="https://packs.cribl.io/dl/cribl-duo-rest-io/latest/cribl-duo-rest-io-latest.crbl",
    force=True,
    allowCustomFunctions=True,
)

      Parameters#

      ParameterTypeRequiredDescription
      idstr | NoneNoUnique identifier for the Pack
      specstr | NoneNoSemver range constraint to apply when resolving the Pack version to install
      versionstr | NoneNoVersion of the Pack, following semantic versioning
      minLogStreamVersionstr | NoneNoMinimum version of Cribl Stream required to run this Pack
      displayNamestr | NoneNoHuman-readable display name for the Pack
      authorstr | NoneNoName or identifier of the Pack author
      descriptionstr | NoneNoBrief description of the Pack and its purpose
      sourcestr | NoneNoSource of the Pack. Provide a staging source ID from PUT /packs, a direct URL to a .crbl file, or a git+<repo-url> Git repository URL. If omitted, an empty Pack is created
      tagsPackTagsParam | NoneNoCategorization tags for the Pack
      allowCustomFunctionsbool | NoneNoIf true or omitted, allow the Pack to use custom JavaScript functions. If false, reject Packs that use custom JavaScript functions
      forcebool | NoneNoIf true, overwrite an existing Pack with the same ID. Otherwise, false

      Response#

      SDKResponse

      (200) PaginatedResponse containing PackInstallInfo objects.

      response = client.packs.install(...)
for item in response.data.items:
    print(item)

      Upgrade a Pack.

      Upgrade the specified Pack. If the Pack includes any user-modified versions of default Cribl Knowledge resources such as lookups, copy the modified files locally for safekeeping before upgrading the Pack. Copy the modified files back to the upgraded Pack after you install it with POST /packs to overwrite the default versions in the Pack. After you upgrade the Pack, update any Routes, Pipelines, Sources, and Destinations that use the previous Pack version so that they reference the upgraded Pack.

      Example Usage#

      response = client.packs.upgrade(
    id="example",
    source="example",
)

      Parameters#

      ParameterTypeRequiredDescription
      idstrYesThe id of the Pack to upgrade. Use the id field from the list response
      sourcestrYesSource of the upgraded Pack. Use the source value returned by PUT /packs for an uploaded file, or provide a direct URL to a .crbl file or a git+<repo-url> Git repository URL
      specstr | NoneNoSemver range constraint to apply when resolving the Pack version to install
      minorbool | NoneNoIf true, allow the upgrade to install a minor (non-breaking) version. Otherwise, false
      allowCustomFunctionsbool | NoneNoIf true or omitted, allow the Pack to use custom JavaScript functions. If false, reject Packs that use custom JavaScript functions

      Response#

      SDKResponse

      (200) PaginatedResponse containing PackInfo objects.

      response = client.packs.upgrade(...)
for item in response.data.items:
    print(item)

      Upload a Pack file. Returns the source ID needed to install the Pack with POST /packs, which you must call separately.

)

      Parameters#

      filenamestrYesFilename of the Pack file to upload
      contentbytesYesBinary content of the Pack file
