      Manage Database Connection configurations.

      client.databaseconnections

      Overview#

      MethodDescription
      createCreate a Database Connection.
      deleteDelete a Database Connection.
      getGet a Database Connection.
      listList all Database Connections.
      updateUpdate a Database Connection.

      Operations#

      create#

      client.databaseconnections.create(...)
await client.databaseconnections.create_async(...)

      Create a Database Connection.

      Create a new Database Connection.

      Example Usage#

      # Example request body for creating a MySQL Database Connection using a connection string with embedded credentials.
client.databaseconnections.create(
    id="mysql-prod-db",
    description="Production MySQL database for customer data",
    databaseType="mysql",
    authType="connectionString",
    connectionString="mysql://yourUsername:yourPassword@mysql.example.com:3306/production?ssl=true",
    connectionTimeout=10000,
    tags="production,mysql,customer-data",
)

      Parameters#

      ParameterTypeRequiredDescription
      idstrYesUnique identifier for the Database Connection
      databaseTypeLiteral["mysql", "oracle", "postgres", "sqlserver", "teradata"]YesType of database engine for the connection. Valid values: “mysql”, “oracle”, “postgres”, “sqlserver”, “teradata”
      authTypeLiteral["configObj", "connectionString", "secret", "secrets"]YesAuthentication method for the Database Connection. Determines how credentials are provided. Valid values: “configObj”, “connectionString”, “secret”, “secrets”
      descriptionstrYesBrief description of the Database Connection
      configObjstr | NoneNoJSON configuration object for advanced SQL Server connection settings
      connectionStringstr | NoneNoDatabase connection string with embedded credentials or server information
      connectionTimeoutint | NoneNoMaximum time (in milliseconds) to wait when establishing the database connection
      credentialsSecretstr | NoneNoName of the stored credentials secret containing username and password for SQL Server configObj authentication
      credsSecretsstr | NoneNoName of the stored credentials secret containing username and password. Used with Oracle connections
      passwordstr | NoneNoDatabase password for authentication. Used with Oracle connections
      requestTimeoutint | NoneNoMaximum time (in milliseconds) to wait for a database query to complete. Applies to SQL Server connections only
      tagsstr | NoneNoComma-separated list of tags for categorizing and filtering Database Connections
      textSecretstr | NoneNoName of the stored text secret containing the connection string
      tlsTLSClientParams | NoneNoTLS client connection settings
      userstr | NoneNoDatabase username for authentication. Used with Oracle connections

      Response#

      SDKResponse

      (200) PaginatedResponse containing the created DatabaseConnectionConfig.

      response = client.databaseconnections.create(...)
for item in response.data.items:
    print(item)

      Oracle with mutual TLS (mTLS)

      # Create an Oracle database connection that authenticates with a client certificate over TCPS. The certificate referenced by `tls.certificateName` must already exist in the system certificates store and contain the client cert, private key, and (for self-signed server chains) the CA cert pinned by the customer.
client.databaseconnections.create(
    id="oracle-mtls-db",
    description="Oracle database reached over TCPS with mutual TLS",
    databaseType="oracle",
    authType="connectionString",
    connectionString="tcps://oracle.example.com:2484/ORCL",
    user="erp_user",
    password="Oracle_Pass456!",
    connectionTimeout=15000,
    tls={
        "disabled": False,
        "rejectUnauthorized": True,
        "certificateName": "oracle-client-cert",
    },
    tags="erp,oracle,mtls,production",
)

      update#

      client.databaseconnections.update(...)
await client.databaseconnections.update_async(...)

      Update a Database Connection.

      Update the specified Database Connection. Provide a complete representation of the Database Connection that you want to update in the request body. This endpoint does not support partial updates. Cribl removes any omitted fields when updating the Database Connection. Confirm that the configuration in your request body is correct before sending the request. If the configuration is incorrect, the updated Database Connection might not function as expected.

      Example Usage#

      # Example request body for updating a MySQL Database Connection using a connection string with embedded credentials. The request body must include a complete representation of the Database Connection that you want to update. This endpoint does not support partial updates.
client.databaseconnections.update(
    id="mysql-prod-db",
    description="Production MySQL database for customer data",
    databaseType="mysql",
    authType="connectionString",
    connectionString="mysql://yourUsername:yourPassword@mysql.example.com:3306/production?ssl=true",
    connectionTimeout=10000,
    tags="production,mysql,customer-data",
)

      Parameters#

      ParameterTypeRequiredDescription
      idstrYesThe id of the Database Connection to update
      databaseTypeLiteral["mysql", "oracle", "postgres", "sqlserver", "teradata"]YesType of database engine for the connection. Valid values: “mysql”, “oracle”, “postgres”, “sqlserver”, “teradata”
      authTypeLiteral["configObj", "connectionString", "secret", "secrets"]YesAuthentication method for the Database Connection. Determines how credentials are provided. Valid values: “configObj”, “connectionString”, “secret”, “secrets”
      descriptionstrYesBrief description of the Database Connection
      configObjstr | NoneNoJSON configuration object for advanced SQL Server connection settings
      connectionStringstr | NoneNoDatabase connection string with embedded credentials or server information
      connectionTimeoutint | NoneNoMaximum time (in milliseconds) to wait when establishing the database connection
      credentialsSecretstr | NoneNoName of the stored credentials secret containing username and password for SQL Server configObj authentication
      credsSecretsstr | NoneNoName of the stored credentials secret containing username and password. Used with Oracle connections
      passwordstr | NoneNoDatabase password for authentication. Used with Oracle connections
      requestTimeoutint | NoneNoMaximum time (in milliseconds) to wait for a database query to complete. Applies to SQL Server connections only
      tagsstr | NoneNoComma-separated list of tags for categorizing and filtering Database Connections
