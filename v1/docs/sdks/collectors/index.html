      Manage Collectors (scheduled data collection jobs).

      client.collectors

      Overview#

      MethodDescription
      createCreate a Collector.
      deleteDelete a Collector.
      getGet a Collector.
      listList all Collectors.
      updateUpdate a Collector.

      Operations#

      create#

      client.collectors.create(...)
await client.collectors.create_async(...)

      Create a Collector.

      Create a new Collector.

      Example Usage#

      # Example request body for creating a Collector that fetches data from a REST API endpoint on a recurring schedule.
client.collectors.create(
    id="rest-collector",
    type="collection",
    schedule={
        "enabled": True,
        "cronSchedule": "0 */4 * * *",
        "tz": "UTC",
        "run": {
            "mode": "run",
            "timeRangeType": "relative",
            "earliest": -300,
            "expression": "true",
            "logLevel": "info",
        },
    },
    collector={
        "type": "rest",
        "sendToRoutes": True,
        "throttleRatePerSec": 100,
        "conf": {
            "collectUrl": "'https://api.example.com/data'",
            "collectMethod": "get",
            "authentication": "none",
            "decodeUrl": True,
            "timeout": 600,
        },
    },
    pipelines=["main"],
    destinations=["default"],
  # ... (see API docs for full payload)
)

      Parameters#

      ParameterTypeRequiredDescription
      collectorCollectorAzureBlob | CollectorCriblLake | CollectorDatabase | CollectorFilesystem | CollectorGoogleCloudStorage | CollectorHealthCheck | CollectorRest | CollectorS3 | CollectorScript | CollectorSplunk | dict[str, object]YesFull saved-job configuration as a typed Collector model (e.g. CollectorS3, CollectorScript) or a plain dict matching the POST /lib/jobs request body

      SDKResponse

      (200) PaginatedResponse containing the created SavedJob.

for item in response.data.items:
