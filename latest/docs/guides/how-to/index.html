      How-to

      • Pagination

      Beyond the Getting Started basics: paging through list results, handling errors, tuning retries and bringing your own HTTP client. Each snippet is self-contained.

      Pagination#

      List operations return SDKResponse[PaginatedResponse[T]] (see PaginatedResponse). Most accept offset and limit; the page carries items, count and, when the server reports it, total_count.

      from cribl_python_sdk import Cribl, Security

with Cribl(
    server_url="https://your-leader:9000",
    security=Security(bearer_auth="your-token"),
) as client:
    offset, limit = 0, 100
    while True:
        page = client.collectors.list(offset=offset, limit=limit).data
        for job in page.items:
            print(job.id)
        offset += page.count
        if page.count < limit or (page.total_count is not None and offset >= page.total_count):
            break

      Errors#

      HTTP errors raise a subclass of APIError carrying status_code, message and the raw response:

      StatusException
      401AuthenticationError
      403AuthorizationError
      404NotFoundError
      422ValidationError
      429RateLimitError
      5xxServerError

      Transport failures raise ConnectionError or TimeoutError; a response that doesn’t match the expected model raises ResponseValidationError.

      from cribl_python_sdk import APIError, Cribl, NotFoundError, Security

with Cribl(
    server_url="https://your-leader:9000",
    security=Security(bearer_auth="your-token"),
) as client:
    try:
        client.pipelines.get("missing")
    except NotFoundError:
        print("no such pipeline")
    except APIError as exc:
        print(exc.status_code, exc.message)

      Retries#

      Requests are retried with exponential backoff (backoff_factor ** attempt seconds), or after the server’s Retry-After / retry-after-ms delay when one is sent. Idempotent methods (GET, HEAD, OPTIONS, PUT, DELETE) retry on 429, 500, 502, 503 and 504; POST and PATCH retry on 429 only.

      from cribl_python_sdk import Cribl, RetryConfig, Security

client = Cribl(
    server_url="https://your-leader:9000",
    security=Security(bearer_auth="your-token"),
    retry_config=RetryConfig(max_attempts=5, backoff_factor=1.5),
)

      RetryConfig(max_attempts=1) disables retries.

      Custom httpx client#

      Pass your own httpx.Client / httpx.AsyncClient for proxies, mTLS, event hooks or custom transports. It is used as-is for control-plane calls, so set base_url to the origin plus /api/v1; timeout and http2 then come from your client, not from Cribl(...).

      import httpx
from cribl_python_sdk import Cribl, Security

client = Cribl(
    server_url="https://your-leader:9000",
    security=Security(bearer_auth="your-token"),
    http_client=httpx.Client(base_url="https://your-leader:9000/api/v1", proxy="http://proxy.internal:3128", verify="/etc/ssl/corp-ca.pem"),
    async_http_client=httpx.AsyncClient(base_url="https://your-leader:9000/api/v1", proxy="http://proxy.internal:3128", verify="/etc/ssl/corp-ca.pem"),
)

      Set debug=True (optionally with debug_logger=) to log requests and responses; credentials are masked.
