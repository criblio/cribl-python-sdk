      Replicate a Worker Group#

      On-prem example_onprem_replicate_worker_group.py

      Clone from an existing group.

      This example is for on-prem deployments only.

      Prerequisites#

      • pip install cribl-python-sdk
      • CRIBL_SERVER_URL, CRIBL_USERNAME, CRIBL_PASSWORD env vars
      • An existing source Worker Group

      Environment variables#

      VariableDefault
      CRIBL_SERVER_URLhttp://localhost:9000
      CRIBL_USERNAMEadmin
      CRIBL_PASSWORDadmin
      CRIBL_SOURCE_GROUPmy-worker-group
      CRIBL_REPLICA_GROUPmy-replica-group
