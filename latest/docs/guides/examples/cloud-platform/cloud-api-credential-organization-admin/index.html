      Create a Cribl.Cloud API Credential (Organization Admin)#

      Cribl.Cloud example_cloud_api_credential_organization_admin.py

      Creates a new API Credential with the Admin role on the Organization. That role applies across the Organization, including all Workspaces and products (no Workspace or product matrix is required).

      The create response includes clientSecret once. Do not print or log it. Store it securely if you will use the new credential later.

      https://docs.cribl.io/cribl-as-code/sdks-auth/#sdks-auth-cloud

      This example is for Cribl.Cloud only (cribl.cloud.api_credentials).

      Prerequisites#

      • pip install cribl-python-sdk
      • CRIBL_CLIENT_ID, CRIBL_CLIENT_SECRET (an existing API Credential, to authenticate)
      • CRIBL_ORGANIZATION_ID
      • CRIBL_CLOUD_URL (workspace origin; still required by the client constructor)

      Environment variables#

      VariableDefault
      CRIBL_CLIENT_IDyour-client-id
      CRIBL_CLIENT_SECRETyour-client-secret
      CRIBL_ORGANIZATION_IDyour-org-id
      CRIBL_CLOUD_URLhttps://main-your-org.cribl.cloud
