      InputCollection — a Source variant.

      Fields#

      FieldTypeRequiredDescription
      typeLiteral["collection"]No
      idstr | NoneNoUnique name for this input
      disabledbool | NoneNoIf true, the Source is disabled and will not collect data.
      pipelinestr | NoneNoPipeline to process results
      sendToRoutesbool | NoneNoSend events to normal routing and event processing. Disable to select a specific Pipeline/Destination combination.
      environmentstr | NoneNoOptionally, enable this config only on a specified Git branch. If empty, will be enabled everywhere.
      pqEnabledbool | NoneNoUse a disk queue to minimize data loss when connected services block. See Cribl Docs for PQ defaults (Cribl-managed Cloud Workers) and configuration options (on-prem and hybrid Workers).
      streamtagslist[str] | NoneNoMetadata tags used for categorization and filtering.
      criblSourceProvenanceInputProvenanceTypeOptional | NoneNoRead-only metadata that records how the Source was created. Preserved on update when omitted from the request body. Cannot be set on create.
      connectionslist[ConnectionConfInputCollection] | NoneNoDirect connections to Destinations, and optionally via a Pipeline or a Pack
      pqPqType | NoneNoPersistent queue settings for this Source.
      breakerRulesetslist[str] | NoneNoA list of event-breaking rulesets that will be applied, in order, to the input data stream
      staleChannelFlushMsfloat | NoneNoHow long (in milliseconds) the Event Breaker will wait for new data to be sent to a specific channel before flushing the data stream out, as is, to the Pipelines
      preprocessPreprocessType | NoneNoOptional preprocessing step that pipes collected data through an external command before ingestion.
      throttleRatePerSecstr | NoneNoRate (in bytes per second) to throttle while writing to an output. Accepts values with multiple-byte units, such as KB, MB, and GB. (Example: 42 MB) Default value of 0 specifies no throttling.
      metadatalist[HecTokenMetadataParam] | NoneNoFields to add to events from this input
      outputstr | NoneNoDestination to send results to
      xtemplate_environmentstr | NoneNoBinds ’environment’ to a variable for dynamic value resolution. Set to variable ID (pack-scoped) or ‘cribl.’/’edge.’ prefixed ID (group-scoped). Variable value overrides ’environment’ at runtime.
      xtemplate_streamtagsstr | NoneNoBinds ‘streamtags’ to a variable for dynamic value resolution. Set to variable ID (pack-scoped) or ‘cribl.’/’edge.’ prefixed ID (group-scoped). Variable value overrides ‘streamtags’ at runtime.
