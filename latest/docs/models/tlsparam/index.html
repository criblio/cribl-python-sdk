      TLS client configuration.

      Fields#

      FieldTypeRequiredDescription
      caPathstrYesPath to PEM-encoded CA certificate.
      certPathstrYesPath to PEM-encoded TLS certificate.
      certificateNamestrYesCertificate name for validation.
      disabledboolYesIf true, TLS is disabled for this connection.
      maxVersionLiteral["TLSv1.3", "TLSv1.2", "TLSv1.1", "TLSv1"]YesMaximum TLS protocol version to accept.
      minVersionLiteral["TLSv1.3", "TLSv1.2", "TLSv1.1", "TLSv1"]YesMinimum TLS protocol version to require.
      passphrasestrYesPassphrase to decrypt the TLS private key.
      privKeyPathstrYesPath to PEM-encoded TLS private key.
      rejectUnauthorizedboolYesIf true, reject unverifiable certificates.
      servernamestrYesExpected server name for SNI.
