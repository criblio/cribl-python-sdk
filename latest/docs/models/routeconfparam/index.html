      RouteConfParam

      • Fields
      • Used by
      • Example

      A Route configuration entry for create/update requests.

      Fields#

      FieldTypeRequiredDescription
      idstrYesUnique identifier for the Route. If omitted, the server generates a deterministic identifier.
      namestrYesName of the Route.
      filterstrYesJavaScript expression to select events for routing.
      pipelinestrYesPipeline that the Route sends matching events to.
      outputstrYesDestination that the Route sends matching events to after the Pipeline processes the events.
      outputExpressionstrYesJavaScript expression to evaluate for dynamic Destination selection. Evaluation occurs when the Route is constructed, not for each event.
      enableOutputExpressionboolYesIf true, use the outputExpression for dynamic Destination selection.
      finalboolYesIf true (default), matched events do not continue to the next Route. If false, all events continue to the next Route. Must be false to clone events.
      disabledboolYesIf true, disable the Route.
      descriptionstrYesBrief description of the Route.
      cloneslist[dict[str, str]]YesArray of clone configurations, each with a key-value pair to set or overwrite in cloned events. Original events continue to the next Route.
      groupIdstrYesUnique identifier for the Route Group that the Route is associated with.
      contextstrYesContext for the Route: ‘group’ (Worker Group or Edge Fleet) or ‘pack’.
      targetContextstrYesTarget context for subsequent event processing after applying the Route.
      autoParseboolYesIf true, detect each matched event’s datatype and extract fields from _raw before the Pipeline processes the event. Otherwise, false (the default).

      Used by#

      • client.routes.append()
      • client.routes.update()

}
