      A data source (input). Base type for all input variants.

      Fields#

      FieldTypeRequiredDescription
      idstr | NoneNoUnique identifier for this source.
      typestr | NoneNoSource type (e.g. ‘syslog’, ‘http’, ‘splunk_hec’).
      disabledbool | NoneNoIf true, source is not active.
      pipelinestr | NoneNoPipeline ID to process events from this source.
