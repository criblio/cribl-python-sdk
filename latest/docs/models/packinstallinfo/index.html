      Information about an installed pack.

      Fields#

      FieldTypeRequiredDescription
      idstr | NoneNoUnique identifier.
      displayNamestr | NoneNoHuman-readable display name for the Pack.
      descriptionstr | NoneNoBrief description of the Pack and its purpose.
      authorstr | NoneNoName or identifier of the Pack author.
      versionstr | NoneNoVersion of the Pack, following semantic versioning.
      sourcestr | NoneNoSource of the Pack — a file path, URL, or Git URL from which the Pack was installed.
      specstr | NoneNoSemver range constraint that was applied when the Pack was installed.
      collectorsfloat | NoneNoNumber of Collectors (saved jobs) configured within the Pack.
      inputsfloat | NoneNoNumber of Sources configured within the Pack.
      outputsfloat | NoneNoNumber of Destinations configured within the Pack.
      exportslist[str] | NoneNoList of entity IDs exported by this Pack and available for use outside the Pack context.
      dependenciesdict[str, str] | NoneNoMap of Pack dependency identifiers to their version constraints.
      settingsdict[str, Any] | NoneNoPack-specific settings object. Contents vary by Pack.
      tagsPackTags | NoneNoCategorization tags for the Pack.
      isDisabledbool | NoneNoIf true, the Pack is disabled.
      minLogStreamVersionstr | NoneNoMinimum version of Cribl Stream required to run this Pack.
      warningslist[str] | NoneNoList of warning messages generated during Pack installation, if any.
      srcGroupstr | NoneNoFleet or group id this entity was inherited from when served by a Config Helper for a child fleet. Present when inherited from parent, including when the child has a local overlay. Omitted when the entity is local and not inherited. Display-only; never persisted.
      srcOverriddenbool | NoneNoIf true, the child fleet has a local overlay on an inherited entity. Omitted when inherited and unmodified, or when local and not inherited. Display-only; never persisted.
