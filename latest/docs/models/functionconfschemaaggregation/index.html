      FunctionConfSchemaAggregation

      • Fields
      • Example

      Base for all SDK models. extra=‘allow’ captures unknown fields in .model_extra.

      Fields#

      FieldTypeRequiredDescription
      passthroughbool | NoneNoPass through the original events along with the aggregation events
      preserveGroupBysbool | NoneNoPreserve the structure of the original aggregation event’s groupby fields
      sufficientStatsOnlybool | NoneNoOutput only statistics that are sufficient for the supplied aggregations
      metricsModebool | NoneNoEnable to output the aggregates as metrics. When disabled, aggregates are output as events.
      prefixstr | NoneNoA prefix that is prepended to all of the fields output by this Aggregations Function
      timeWindowstr | NoneNoThe time span of the tumbling window for aggregating events. Must be a valid time string (such as 10s).
      aggregationslist[str] | NoneNoAggregate function to perform on events. Example: sum(bytes).where(action==‘REJECT’).as(TotalBytes)
      groupbyslist[str] | NoneNoOptional: One or more fields to group aggregates by. Supports wildcard expressions. Warning: Using wildcard ‘*’ causes all fields in the event to be included, which can result in high cardinality and increased memory usage. Exclude fields that can result in high cardinality before using wildcards. Example: !_time, !_numericValue, *
      flushEventLimitfloat | NoneNoThe maximum number of events to include in any given aggregation event
      flushMemLimitstr | NoneNoThe memory usage limit to impose upon aggregations. Defaults to 80% of the process memory; value configured above default limit is ignored. Accepts numerals with units like KB and MB (example: 128MB).
      cumulativebool | NoneNoEnable to retain aggregations for cumulative aggregations when flushing out an aggregation table event. When disabled (the default), aggregations are reset to 0 on flush.
      searchAggModestr | NoneNoAllows Cribl Search-specific aggregation configuration
      addlist[FunctionConfSchemaAggregationAddItem] | NoneNoSet of key-value pairs to evaluate and add/set
      shouldTreatDotsAsLiteralsbool | NoneNoTreat dots in dimension names as literals. This is useful for top-level dimensions that contain dots, such as ‘service.name’.
      flushOnInputClosebool | NoneNoFlush aggregations when an input stream is closed. If disabled, Time Window Settings control flush behavior.
      printUndefinedsbool | NoneNoWhen enabled (e.g. for Cribl Search), convert undefined expression results to null so requested-but-missing fields appear in JSON output. When disabled (default), undefined is preserved.
      lagTolerancestr | NoneNoThe tumbling window tolerance to late events. Must be a valid time string (such as 10s). Defaults to the smaller of Time Window and 1 minute.
      idleTimeLimitstr | NoneNoHow long to wait before flushing a bucket that has not received events. Must be a valid time string (such as 10s). Defaults to the smaller of Time Window and 1 minute.

      from cribl_python_sdk.models.nested import FunctionConfSchemaAggregation

obj = FunctionConfSchemaAggregation(
    passthrough=True,
    preserveGroupBys=True,
    sufficientStatsOnly=True,
