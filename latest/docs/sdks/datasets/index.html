      Operations#

      create#

      client.datasets.create(...)

      Create Lake Datasets (Cribl.Cloud only).

      Creates one or more Lake Datasets in the specified Lake in a single transaction (Cribl.Cloud only). Send a single Lake Dataset object to create just one, or an array to bulk-create multiple. When an array is sent, the response is { items, errors } – items contains the successfully created Lake Datasets, and errors contains an entry ({ id, reason }) for each Lake Dataset that failed validation, so a per-item failure does not fail the rest of the batch.

      Example Usage#

      # Example request body for creating a Lake Dataset in JSON format with a 90-day retention period.
client.datasets.create(
    id="web_access_logs",
    description="Web server access logs",
    storageLocationId="my-storage-location",
    format="json",
    retentionPeriodInDays=90,
    acceleratedFields=[
        "host",
        "status",
    ],
)

      Parameters#

      ParameterTypeRequiredDefaultDescription
      lakeIdstrYes—The id of the Lake to create the Lake Datasets in
      idstrYes—Unique identifier for the Dataset
      acceleratedFieldslist[str] | NoneNo—Accelerated fields for the Dataset. Data is partitioned by these fields in storage to improve query performance
      allowRecordErasurebool | NoneNo—If true, the Dataset is opted in to Lake Record Erasure
      bucketNamestr | NoneNo—Name of the legacy Cribl Lake bucket that backs the Dataset. Mutually exclusive with storageLocationId
      cacheConnectionCacheConnectionParam | NoneNo—Lakehouse cache connection settings for the Dataset
      deletionStartedAtint | NoneNo—Timestamp (in Unix time) when Dataset deletion was initiated, in milliseconds
      descriptionstr | NoneNo—Brief description of the Dataset
      formatstr | NoneNo—Storage format used for data persisted in the Dataset
      httpDAUsedbool | NoneNo—If true, the Dataset is used by Direct Access HTTP. Otherwise, false
      metricsDatasetMetricsParam | NoneNo—Most recent Dataset metrics snapshot
      providerPathstr | NoneNo—Storage path within the provider (for example an S3 prefix or Azure container)
      retentionPeriodInDaysint | NoneNo—Dataset retention period, in days
      searchConfigDatasetSearchConfigParam | NoneNo—Search configuration for the Dataset
      storageClassstr | NoneNo—Storage class used for objects written to the Dataset
      storageLocationIdstr | NoneNo—Unique identifier for the Storage Location that backs the Dataset. Mutually exclusive with bucketName
      viewNamestr | NoneNo—Name of the ClickHouse view for the Dataset on the Lakehouse

      Response#

      SDKResponse

      (200) PaginatedResponse containing the created CriblLakeDataset.

      response = client.datasets.create(...)
for item in response.data.items:
    print(item)

      Create a Lake Dataset in Parquet format

      # Example request body for creating a Lake Dataset in Parquet format with a 365-day retention period and search configuration.
client.datasets.create(
    id="security_events",
    description="Security event data in Parquet format",
    storageLocationId="my-storage-location",
    format="parquet",
    retentionPeriodInDays=365,
    searchConfig={
        "datatypes": [
            "palo_alto_firewall",
            "crowdstrike_fdr",
        ],
    },
)

      Create a minimal Lake Dataset

      # Example request body for creating a Lake Dataset with only the required body parameters.
client.datasets.create(
    id="app_logs",
)

      Bulk create Lake Datasets

      # Example request body for creating multiple new Lake Datasets in a single request. Send an array of objects — one per Lake Dataset to create, using the same fields as a single-item create (this example shows one such element). The response is { items, errors } : items contains the created Lake Datasets, and errors contains { id, reason } entries for any Lake Datasets that failed validation.
client.datasets.create(
    id="web_access_logs",
    description="Web server access logs",
    storageLocationId="my-storage-location",
    format="json",
    retentionPeriodInDays=90,
    acceleratedFields=[
        "host",
        "status",
    ],
)

      list#

      client.datasets.list(...)

      List all Lake Datasets (Cribl.Cloud only).

      Get a list of all Lake Datasets in the specified Lake (Cribl.Cloud only).

      Example Usage#

      response = client.datasets.list(
    lakeId="example",
)

      Parameters#

      ParameterTypeRequiredDefaultDescription
      lakeIdstrYes—The id of the Lake that contains the Lake Datasets to list
      storageLocationIdstr | NoneNo—Filter datasets by storage location ID. Use default for default storage location
      formatstr | NoneNo—Filter datasets by format. Set to ddss to return only DDSS datasets
      excludeDDSSbool | NoneNo—Exclude DDSS format datasets from the response
      excludeNetskopebool | NoneNo—Exclude Netskope format datasets from the response
      excludeDeletedbool | NoneNo—Exclude deleted datasets from the response
      excludeInternalbool | NoneNo—Exclude internal datasets (those with IDs starting with cribl_) from the response
      excludeBYOSbool | NoneNo—Exclude BYOS (Bring Your Own Storage) datasets from the response
      includeMetricsbool | NoneNo—Set to true to include storage metrics for each Lake Dataset. Otherwise, false (default). Requires a Cribl Lake metrics license
      offsetint | NoneNo—Starting point for catalog-backed pagination. Requires limit
      limitint | NoneNo—Page size for catalog-backed pagination. Requires offset
      orderBystr | NoneNo—Catalog sort field when paginating: name, createdAt, updatedAt, providerPath, type, or retentionPeriodInDays. Defaults to name
      orderDirstr | NoneNo—Sort direction when paginating: asc or desc. Defaults to asc
      namestr | NoneNo—Exact dataset name match (catalog path, with pagination)
      nameContainsstr | NoneNo—Case-insensitive substring match on dataset name (catalog path, with pagination)
      providerPathContainsstr | NoneNo—Case-insensitive substring match on provider path (catalog path, with pagination)
      descriptionContainsstr | NoneNo—Case-insensitive substring match on description (catalog path, with pagination)
