      install#

      client.packs.install(...)

      Install a Pack.

      Install a Pack. To install an uploaded Pack, provide the source value from the PUT /packs response as the source parameter in the request body. To install a Pack by importing from a URL, provide the direct URL location of the .crbl file for the Pack as the source parameter in the request body. To install a Pack by importing from a Git repository, provide git+<repo-url> as the source parameter in the request body. If you do not include the source parameter in the request body, an empty Pack is created.

      Example Usage#

      # Example request body for installing a Pack directly from the Cribl Pack Dispensary using a download URL.
client.packs.install(
    source="https://packs.cribl.io/dl/cribl-duo-rest-io/latest/cribl-duo-rest-io-latest.crbl",
    force=True,
    allowCustomFunctions=True,
)

      Parameters#

      ParameterTypeRequiredDefaultDescription
      idstr | NoneNo—Unique identifier for the Pack
      specstr | NoneNo—Semver range constraint to apply when resolving the Pack version to install
      versionstr | NoneNo—Version of the Pack, following semantic versioning
      minLogStreamVersionstr | NoneNo—Minimum version of Cribl Stream required to run this Pack
      displayNamestr | NoneNo—Human-readable display name for the Pack
      authorstr | NoneNo—Name or identifier of the Pack author
      descriptionstr | NoneNo—Brief description of the Pack and its purpose
      sourcestr | NoneNo—Source of the Pack. Provide a staging source ID from PUT /packs, a direct URL to a .crbl file, or a git+<repo-url> Git repository URL. If omitted, an empty Pack is created
      tagsPackTagsParam | NoneNo—Categorization tags for the Pack
      allowCustomFunctionsbool | NoneNo—If true or omitted, allow the Pack to use custom JavaScript functions. If false, reject Packs that use custom JavaScript functions
      forcebool | NoneNo—If true, overwrite an existing Pack with the same ID. Otherwise, false

      Response#

      SDKResponse

      (200) PaginatedResponse containing PackInstallInfo objects.

      response = client.packs.install(...)
for item in response.data.items:
    print(item)

      upgrade#

      client.packs.upgrade(...)

      Upgrade a Pack.

      Upgrade the specified Pack. If the Pack includes any user-modified versions of default Cribl Knowledge resources such as lookups, copy the modified files locally for safekeeping before upgrading the Pack. Copy the modified files back to the upgraded Pack after you install it with POST /packs to overwrite the default versions in the Pack. After you upgrade the Pack, update any Routes, Pipelines, Sources, and Destinations that use the previous Pack version so that they reference the upgraded Pack.

      Example Usage#

      response = client.packs.upgrade(
    id="example",
    source="example",
)

      Parameters#

      ParameterTypeRequiredDefaultDescription
      idstrYes—The id of the Pack to upgrade. Use the id field from the list response
      sourcestrYes—Source of the upgraded Pack. Use the source value returned by PUT /packs for an uploaded file, or provide a direct URL to a .crbl file or a git+<repo-url> Git repository URL
      specstr | NoneNo—Semver range constraint to apply when resolving the Pack version to install
      minorbool | NoneNo—If true, allow the upgrade to install a minor (non-breaking) version. Otherwise, false
      allowCustomFunctionsbool | NoneNo—If true or omitted, allow the Pack to use custom JavaScript functions. If false, reject Packs that use custom JavaScript functions

      Response#

      SDKResponse

      (200) PaginatedResponse containing PackInfo objects.

      response = client.packs.upgrade(...)
for item in response.data.items:
    print(item)
