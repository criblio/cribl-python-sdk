      Destinations › Samples

      destinations.samples

      Sample/test operations for Destinations

      client.destinations.samples

      Overview#

      MethodDescription
      createSend sample event data to a Destination.
      getGet sample event data for a Destination.

      Operations#

      create#

      client.destinations.samples.create(...)

      Send sample event data to a Destination.

      Send sample event data to the specified Destination to validate the configuration or test connectivity.

      Example Usage#

      # Example request body for sending a single test event to the Destination.
client.destinations.samples.create(
 events=[
        {"_raw": "This is a test event", "source": "test", "sourcetype": "manual"},
    ],
)

      Parameters#

      ParameterTypeRequiredDefaultDescription
      idstrYes—The id of the Destination to send sample event data to
      eventslist[dict[str, Any]]Yes—Array of event objects to send to the Destination for testing
      packstr | NoneNo—Pack ID. If provided, scopes the operation to the specified Pack

      Response#

      SDKResponse

      (200) PaginatedResponse containing OutputTestResponse objects.

      response = client.destinations.samples.create(...)
for item in response.data.items:
    print(item)

      Errors#

      This operation may raise the following SDK exceptions.

      ErrorStatus CodeDescription
      ValidationError400Failed validation or malformed input — missing or invalid events.
      AuthenticationError401Authentication failed (missing or invalid credentials or Bearer token).
      ServerError500Unexpected server error.

      Send multiple test events

      # Example request body for sending multiple test events to the Destination.
client.destinations.samples.create(
    events=[
        {"_raw": "Test event 1", "source": "test", "sourcetype": "manual"},
        {"_raw": "Test event 2", "source": "test", "sourcetype": "manual"},
    ],
)

      Successful Destination test — Response

      # Example response when a Destination successfully receives sample event data.
{
    "items": [
        {
            "outputId": "splunk-hec-output",
            "success": True,
            "successDetail": "Successfully sent 1 event(s) to the Destination.",
        },
    ],
    "count": 1,
}

      Failed Destination test — Response

      # Example response when a Destination fails to receive sample event data.
{
    "items": [
        {
            "outputId": "s3-output",
            "success": False,
            "error": "Connection timed out after 30000ms",
        },
    ],
    "count": 1,
}

      get#

      client.destinations.samples.get(...)

      Get sample event data for a Destination.

      Get sample event data for the specified Destination to validate the configuration or test connectivity.

      Example Usage#

      response = client.destinations.samples.get(
    id="example",
)

      Parameters#

      ParameterTypeRequiredDefaultDescription
      idstrYes—The id of the Destination to get sample event data for
      packstr | NoneNo—Pack ID. If provided, scopes the operation to the specified Pack

      Response#

      SDKResponse

      (200) PaginatedResponse containing the requested OutputSamplesResponse.

      response = client.destinations.samples.get(...)
for item in response.data.items:
    print(item)

      ErrorStatus CodeDescription
