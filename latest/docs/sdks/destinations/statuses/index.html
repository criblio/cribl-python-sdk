      destinations.statuses

      Status operations for Destinations

      client.destinations.statuses

      Overview#

      MethodDescription
      getGet the status of a Destination.
      listList the status of all Destinations.

      Operations#

      get#

      client.destinations.statuses.get(...)

      Get the status of a Destination.

      Get the status and optional metrics for the specified Destination.

      Example Usage#

      response = client.destinations.statuses.get(
 id="example",
)

      Parameters#

      ParameterTypeRequiredDefaultDescription
      idstrYes—The id of the Destination to get the status for
      metricsbool | NoneNo—Set to true to include metrics for each Destination. Otherwise, false (default)
      typebool | NoneNo—Set to true to prefix the Destination id with the Destination type. Otherwise, false (default)
      packstr | NoneNo—Pack ID. If provided, scopes the operation to the specified Pack

      Response#

      SDKResponse

      (200) PaginatedResponse containing the requested OutputStatus.

      response = client.destinations.statuses.get(...)
for item in response.data.items:
    print(item)

      list#

      client.destinations.statuses.list(...)

      List the status of all Destinations.

      List status information and optional metrics for all configured Destinations in the Worker Group or Edge Fleet.

      Example Usage#

      response = client.destinations.statuses.list()

      Parameters#

      ParameterTypeRequiredDefaultDescription
      metricsbool | NoneNo—Set to true to include metrics for each Destination. Otherwise, false (default)
      typebool | NoneNo—Set to true to prefix the Destination id with the Destination type. Otherwise, false (default)
      offsetint | NoneNo—Starting point from which to retrieve results for this request. Use with limit to paginate the response into manageable batches
      limitint | NoneNo—Maximum number of items to return in the response for this request. Use with offset to paginate the response into manageable batches
      packstr | NoneNo—Pack ID. If provided, scopes the operation to the specified Pack

      Response#

      SDKResponse

      (200) PaginatedResponse containing a list of OutputStatus objects.

      response = client.destinations.statuses.list(...)
for item in response.data.items:
    print(item)

      ErrorStatus CodeDescription
      ValidationError400Failed validation or malformed input, such as missing or invalid parameters.
      AuthenticationError401Authentication failed (missing or invalid credentials or Bearer token).
