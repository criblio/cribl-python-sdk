      System › Captures

      system.captures

      Capture operations

      client.system.captures

      create#

      client.system.captures.create(...)
await client.system.captures.create_async(...)

      Capture live data as an NDJSON stream.

      Initiate a live data capture from Cribl Workers. Yields CapturedEvent objects as they arrive over the wire (line-delimited JSON).

      Example Usage#

      # Example request body for capturing events by sourcetype.
client.system.captures.create(
 filter="sourcetype===\"pan:traffic\"",
    maxEvents=100,
    duration=5,
    level=0,
)

      Parameters#

      ParameterTypeRequiredDefaultDescription
      durationint | NoneNo5Amount of time to keep capture open, in seconds
      filterstr | NoneNo—JavaScript expression evaluated against each event to determine whether an event is included in the capture output. Expressions can reference any event field and use logical operators. If not provided, all events are captured
      levelint | NoneNo0Stage at which events are captured
      maxEventsint | NoneNo100Maximum number of events to capture
      stepDurationint | NoneNo5How long to wait before increasing the capture sample size. Specify 1 second or longer
      workerIdstr | NoneNo—Unique ID of the Worker
      workerThresholdint | NoneNo50Maximum number of Workers that can capture initially. A value of 0 means unlimited (all available Workers can capture)

      Response#

      Generator[CapturedEvent]

      for event in client.system.captures.create(...):
    print(event)

      Errors#

      This operation may raise the following SDK exceptions.

      ErrorStatus CodeDescription
      ValidationError400Failed validation or malformed input — No worker nodes are connected to this worker group.
      AuthenticationError401Authentication failed (missing or invalid credentials or Bearer token).
      ServerError500Unexpected server error.

      Capture events using the AND operator to specify multiple conditions

      # Example request body for capturing events using the AND operator to specify multiple conditions.
client.system.captures.create(
    filter="sourcetype===\"pan:traffic\" && src_zone===\"trusted\"",
    maxEvents=100,
    duration=5,
    level=0,
)

      Capture events using dot notation to specify nested fields

      # Example request body for capturing events using dot notation to specify nested fields.
client.system.captures.create(
    filter="sourcetype===\"pan:traffic\" && dest_geoip.country.iso_code === \"US\"",
    maxEvents=100,
    duration=5,
    level=0,
)

      Capture with a complex filter that uses JavaScript methods

      # Example request body for capturing with a complex filter that uses JavaScript methods.
client.system.captures.create(
    filter="__inputId.startsWith(\"http:\") && status >= 400 && status < 500",
    maxEvents=500,
    duration=15,
    level=1,
)

      # Example response for streaming one captured event as an NDJSON line from a live data capture.

}
