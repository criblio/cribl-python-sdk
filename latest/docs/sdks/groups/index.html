      Manage Worker Groups, Outpost Groups, and Edge Fleets.

      client.groups

      Overview#

      MethodDescription
      createCreate a Worker Group, Outpost Group, or Edge Fleet.
      deleteDelete a Worker Group, Outpost Group, or Edge Fleet.
      deployDeploy commits to a Worker Group, Outpost Group, or Edge Fleet.
      getGet a Worker Group, Outpost Group, or Edge Fleet.

      updateUpdate a Worker Group, Outpost Group, or Edge Fleet.

      Operations#

      create#

      client.groups.create(...)
await client.groups.create_async(...)

      Create a Worker Group, Outpost Group, or Edge Fleet.

      Create a new Worker Group, Outpost Group, or Edge Fleet for the specified Cribl product.

      Example Usage#

      # Example request body for creating a Worker Group on Cribl.Cloud sized for a low-ingest deployment.
client.groups.create(
    id="goatCloudIanWg",
    name="goatcloudianwg",
    cloud={"provider": "aws", "region": "us-west-2"},
    workerRemoteAccess=True,
    type="stream",
    onPrem=False,
    estimatedIngestRate=2048,
    provisioned=True,
)

      Parameters#

      ParameterTypeRequiredDefaultDescription
      productLiteral["stream", "edge", "outpost"]No"stream"Name of the Cribl product to add the Worker Group, Outpost Group, or Edge Fleet to. Valid values: “stream”, “edge”, “outpost”
      idstrYes—Unique identifier
      cloudCloudParam | NoneNo—Cloud provider and region details for a Cribl.Cloud Worker Group
      collectorsHaEnabledbool | NoneNo—Keeps Collector jobs running if the Leader Node fails. Applies only to Stream Worker Groups. Always true for Cribl.Cloud groups; defaults to false for on-prem groups
      descriptionstr | NoneNo—Brief description of the Worker Group, Outpost Group, or Edge Fleet
      estimatedIngestRateEstimatedIngestRate | int | NoneNo—Estimated ingest rate for a Cribl.Cloud Worker Group, in GB/sec
      inheritsstr | NoneNo—The id of the parent Edge Fleet. If provided, this Fleet inherits configuration from the specified parent Fleet. Applies only to Edge Fleets
      isFleetbool | NoneNo—Indicates whether this is an Edge Fleet. Deprecated
      isSearchbool | NoneNo—Indicates whether this is an internal Search Group. Deprecated
      maxWorkerAgestr | NoneNo—Maximum duration a Worker or Node can remain disconnected before the Leader removes it
      namestr | NoneNo—Name of the Worker Group, Outpost Group, or Edge Fleet
      onPrembool | NoneNo—If true, the Group or Fleet uses customer-hosted (on-prem) workers. If false, managed in Cribl.Cloud
      provisionedbool | NoneNo—If true, the Cribl.Cloud Worker Group has active Workers provisioned
      sourceGroupIdstr | NoneNo—The id of an existing Group or Fleet to copy configuration from when creating a new Group or Fleet
      streamtagslist[str] | NoneNo—Metadata tags for categorization, filtering, and tag-based routing and policy application
      tagsstr | NoneNo—Legacy system-level tags. Use streamtags instead
      type
      Literal[…] | None (6 values)Literal["edge", "lake_access", "local_search", "outpost", "search", "stream"] | None
      		No—Explicit type of the Worker Group, Outpost Group, or Edge Fleet. Valid values: “edge”, “lake_access”, “local_search”, “outpost”, “search”, “stream”
      upgradeVersionstr | NoneNo—Target software upgrade version. Applies only to Outpost Groups and Edge Fleets
      workerRemoteAccessbool | NoneNo—If true, the Leader allows remote access (teleporting) into the Workers or Nodes

      update#

      client.groups.update(...)
await client.groups.update_async(...)

      Update a Worker Group, Outpost Group, or Edge Fleet.

      Update the specified Worker Group, Outpost Group, or Edge Fleet. Provide a complete representation of the Group or Fleet that you want to update in the request body. This endpoint does not support partial updates. Cribl removes any omitted fields when updating the Group or Fleet. Confirm that the configuration in your request body is correct before sending the request. If the configuration is incorrect, the updated Group or Fleet might not function as expected. Warning: Do not change the values for the following parameters in the body of PATCH requests. The request body must include the values as they appear in the GET response: configVersion, deployingWorkerCount, incompatibleWorkerCount, workerCount, lookupDeployments.

      Example Usage#

      # Example request body for scaling a Cribl.Cloud Worker Group to handle higher throughput. The request body must include a complete representation of the Group or Fleet that you want to update. This endpoint does not support partial updates.
client.groups.update(
    id="goatCloudIanWg",
    name="goatcloudianwg",
    description="Scaled Worker Group with estimated ingest rate of 4096 (48 MB/s, 21 Worker Processes) for increased capacity",
    cloud={"provider": "aws", "region": "us-west-2"},
    workerRemoteAccess=True,
    type="stream",
    onPrem=False,
    estimatedIngestRate=4096,
    provisioned=True,
    configVersion="abc1234",
    workerCount=3,
    incompatibleWorkerCount=0,
    deployingWorkerCount=0,
    lookupDeployments=[],
)
