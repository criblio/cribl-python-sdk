      Sources › HEC Tokens

      HEC token operations for Sources (sources.hecTokens).

      client.sources.hec_tokens

      Overview#

      MethodDescription
      createAdd an HEC token and optional metadata to a Splunk HEC Source.
      updateUpdate metadata for an HEC token for a Splunk HEC Source.

      Operations#

      create#

      client.sources.hec_tokens.create(...)

      Add an HEC token and optional metadata to a Splunk HEC Source.

      Add an HEC token and optional metadata to the specified Splunk HEC Source.

      Example Usage#

      # Example request body for adding an HEC token with metadata to a Splunk HEC Source.
client.sources.hec_tokens.create(
    enabled=True,
    metadata=[{"name": "fieldX", "value": "valueX"}],
    token="12345678901",
)

      Parameters#

      ParameterTypeRequiredDefaultDescription
      idstrYes—The id of the Splunk HEC Source
      tokenstrYes—The HEC token value to add to the Splunk HEC Source
      descriptionstr | NoneNo—Brief description for the HEC token
      enabledbool | NoneNo—If true, the HEC token is enabled. Otherwise, false
      allowedIndexesAtTokenlist[str] | NoneNo—List of index names that the HEC token is allowed to write to
      metadatalist[HecTokenMetadataParam] | NoneNo—Array of key-value pairs to associate with the HEC token for tagging, categorization, or providing additional context. Each item in the array is an object with a name and a value
      packstr | NoneNo—Pack ID. If provided, scopes the operation to the specified Pack

      Response#

      SDKResponse

      (200) PaginatedResponse containing Source objects.

      response = client.sources.hec_tokens.create(...)
for item in response.data.items:
    print(item)

      update#

      Update the metadata for the specified HEC token for the specified Splunk HEC Source.

      Example Usage#

      # Example request body for adding an HEC token with metadata to a Splunk HEC Source.
client.sources.hec_tokens.update(
    enabled=True,
    metadata=[{"name": "fieldX", "value": "valueX"}],
    token="12345678901",
)

      Parameters#

      ParameterTypeRequiredDefaultDescription
      idstrYes—The id of the Splunk HEC Source
      tokenstrYes—The HEC token value whose metadata you want to update. Must match an existing token on the Source
      descriptionstr | NoneNo—Brief description for the HEC token
      enabledbool | NoneNo—If true, the HEC token is enabled. Otherwise, false
      allowedIndexesAtTokenlist[str] | NoneNo—List of index names that the HEC token is allowed to write to
      metadatalist[HecTokenMetadataParam] | NoneNo—Array of key-value pairs to associate with the HEC token for tagging, categorization, or providing additional context. Each item in the array is an object with a name and a value
      packstr | NoneNo—Pack ID. If provided, scopes the operation to the specified Pack
