      • Overview
      • Operations
        • create

        • update

      Manage processing pipelines (create, list, update, delete).

      client.pipelines

      Overview#

      MethodDescription
      createCreate a Pipeline.
      deleteDelete a Pipeline.
      getGet a Pipeline.
      listList all Pipelines.
      updateUpdate a Pipeline.

      Operations#

      create#

      client.pipelines.create(...)
await client.pipelines.create_async(...)

      Create a Pipeline.

      Create a new Pipeline.

      Example Usage#

      # Example request body for creating a new Pipeline with no functions.
client.pipelines.create(
    id="empty-pipeline",
    conf={
        "output": "default",
        "streamtags": [],
        "groups": {},
        "asyncFuncTimeout": 1000,
        "functions": [],
        "description": "",
    },
)

      Parameters#

      ParameterTypeRequiredDescription
      idstrYesUnique identifier for the Pipeline
      confPipelineConfParamYesConfiguration for the Pipeline, including functions and settings
      packstr | NoneNoPack ID. If provided, scopes the operation to the specified Pack

      Response#

      SDKResponse

      (200) PaginatedResponse containing the created Pipeline.

      response = client.pipelines.create(...)
for item in response.data.items:
    print(item)

      Errors#

      This operation may raise the following SDK exceptions.

      ErrorStatus CodeDescription
      ValidationError400Failed validation or malformed input, such as missing or invalid parameters.
      AuthenticationError401Authentication failed (missing or invalid credentials or Bearer token).
      ServerError500Unexpected server error.
